⬡ Two-device setup — no feedback loop

The Performer tab captures and processes your microphone. The Listener tab plays audio through the speaker — open it on a separate device (phone, tablet, another laptop) so the mic and speaker are physically apart.

Audio is relayed between devices using a simple peer-to-peer WebRTC connection via a public signalling relay.

How to connect

  1. On the Performer device: click Start Broadcast and copy the 6-digit Room Code.
  2. On the Listener device: open this same HTML file in a browser, go to Stream / Listener tab, enter the Room Code and click Join as Listener.
  3. The listener opens a fullscreen audio-only player. Processed audio streams live — no mic on the listener device needed.
  4. Or use the Open Listener Window button below to open a second tab on the same machine (only works if they're on different audio devices or headphones are plugged into the performer device).
